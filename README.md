## 42 Learning Journey

Overview of my progression through the 42 Berlin curriculum (Piscine → Core Projects → Systems & Concurrency):  
https://github.com/TheForestGiraffe/42-journey

42 is a project-based software engineering programme focused on low-level C, systems-oriented and object-oriented C++, and Unix/Linux development. The curriculum covers algorithms, data structures, concurrency, networking, debugging and development tooling, with regular use of Bash and Git. Containerized environments (Docker) come later in the programme.

For additional information about 42, please visit https://42berlin.de/.
